
# A Multi-Task Contract Model of Environmental AI Safety

This repository contains the source code and experimental data for the paper, "A Multi-Task Contract Model of Environmental AI Safety," submitted to AAMAS 2026.

## Overview

The deployment of Artificial Intelligence (AI) in high-stakes domains like environmental management creates a critical governance challenge: easily measured performance metrics may not align with true, unobservable system safety. This work tackles this performance-safety dilemma by developing a multi-task principal-agent model to govern a self-interested AI developer. We analytically derive the optimal regulatory contract and prove that to ensure safety, it must use deliberately "muted" incentives for observable performance. We also propose a robust algorithm, Projected Incentive-Preserving Shift (PIPS), that is guaranteed to find the best-achievable, incentive-compatible contract when the ideal contract is not implementable. Through agent-based simulations of a wildfire management case study, we demonstrate that contracts generated by our method significantly improve social welfare compared to realistic heuristic policies.

## Repository Structure

The repository is organized as follows:

-   **`src/`**: Contains the core Python source code for the agent-based model, including agents, contracts, and the simulation model itself.
-   **`experiments/`**: Contains the scripts to run the simulations and generate the plots presented in the paper.
-   **`results/`**: Contains the raw `.csv` data files generated by the experimental scripts.
-   **`figures/`**: Contains the PDF figures generated by the plotting scripts.
-   **`tests/`**: Contains unit and integration tests for the codebase.

## Getting Started

### Prerequisites

The project is developed in Python 3.11. The required packages are listed in `pyproject.toml`.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone url-to-github-repo.git
    cd safety
    ```

2.  **Install the project in editable mode with dependencies:**
    This project uses `pip` for package management. It is recommended to use a virtual environment.
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    pip install -e .
    ```

## Reproducing the Experiments

You can reproduce all the figures from the paper by running the provided scripts. The workflow is designed in two stages: running the simulations to generate data, and then running the plotting scripts to generate the figures from that data. We use the main comparison experiment as an example in the following.

### 1. Run the Simulations

The main experimental scripts are located in the `experiments/` directory.

-   **To run the main comparison experiments (Figures 3 & 4):**
    ```bash
    python experiments/exp_main_comparison.py
    ```
    This will generate `results/main_comparison.csv`.

-   **To run the comparative statics experiment (Figure 5):**
    ```bash
    python experiments/exp_comparative_statics.py
    ```
    This will generate `results/comparative_statics.csv`.

### 2. Generate the Plots

The plotting scripts use the data in the `results/` directory to create the figures.

-   **To generate the main results plot (Figure 3):**
    ```bash
    python experiments/plot_main_results.py
    ```
    This will create `figures/main_comparison.pdf`.

-   **To generate the effort tradeoff plot (Figure 4):**
    ```bash
    python experiments/plot_effort_tradeoff.py
    ```
    This will create `figures/effort_tradeoff.pdf`.

-   **To generate the comparative statics plot (Figure 5):**
    ```bash
    python experiments/plot_comparative_statics.py
    ```
    This will create `figures/comparative_statics.pdf`.
